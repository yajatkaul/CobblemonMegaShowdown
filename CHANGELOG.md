# 1.4+1.8.4+1.21.1-release
### General updates:
- Added many item new tags for addon creators (#mega_showdown:arceus_plate, fusion_device, genesect_drive, ogerpon_mask, oricorio_nectar, origin_form_items, primal_orb, silvally_memory, tera_pouch)
- Updated all existing tags to include some missing entries (#mega_showdown:mega_stone, tera_shard, z_ring)
- Updated advancements to not require legendaries (since they aren't available in the base mod)
- Updated advancements to include the ZA Megas already in Champions
- Updated Mega Absol & Mega Absol Z models & animations
### Recipe changes:
- The Omni Ring can now be crafted from any Mega Accessory/Z Ring/Dynamax Band instead of only Keystones/Sparkling Stones/Wishing Stars specifically
- All Mega stones now require one Blank Mega Stone, two Type Gems, one Diamond & one unique item
- Recipes for Ability Patch & Tera Orb were made a fair bit more expensive
- Tera Pouches now require String instead of Blaze Powder
- The Rotom Catalogue recipe is now shapeless
- Max Honey is now a cooking pot recipe
- Added a Tera Blast TM recipe
### Fixes & Miscellaneous:
- Fixed a bug where riding stats for Mega Absol Z reset upon reverting
- Fixed missing "implemented" tag on Arctibax & Baxcalibur
- Many file (path) optimizations for accessibility
